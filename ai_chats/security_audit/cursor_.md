Если оставить Google Fonts как сейчас, то в `Electron` без интернета шрифты гарантированно работать не будут. Браузерный кэш может помочь только случайно: если этот конкретный шрифт уже был загружен раньше на этой машине и кэш не очищен. На это нельзя опираться для офлайн и изолированного приложения.

“Один раз подгрузить” технически можно, но это плохая модель для desktop-приложения:
- на первой установке без сети шрифт не появится;
- кэш может быть очищен;
- на другом ПК кэша не будет;
- приложение всё равно будет делать внешний запрос, а это ломает изоляцию.

Для `Electron` правильный вариант: хранить шрифты локально и паковать их вместе с приложением.
Обычно делают так:
- кладут `.woff2` в `frontend/src/assets/fonts/` или `public/fonts/`
- подключают через `@font-face`
- используют локальное имя шрифта в теме

Пример:

```css
@font-face {
  font-family: "Inter Tight";
  src: url("./assets/fonts/InterTight-Variable.woff2") format("woff2");
  font-weight: 100 900;
  font-style: normal;
  font-display: swap;
}

@theme {
  --font-sans: "Inter Tight", sans-serif;
}
```

Ещё удобный вариант: взять шрифт через пакет вроде `@fontsource`, если нужна управляемая локальная поставка без внешних URL.

Коротко: да, кэш иногда “спасёт”, но для `Electron` и офлайн-режима шрифты нужно встраивать локально, а не надеяться на одноразовую загрузку. Если хотите, следующим сообщением могу сразу показать, какой способ для вашего проекта будет самым простым и безопасным.
