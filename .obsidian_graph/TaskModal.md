# TaskModal.tsx

Модальная форма создания/редактирования задачи. Поля: название, даты, приоритет, статус, описание, ссылка, ресурсы, кастомные поля. Кастомные поля можно сортировать через drag-and-drop внутри модала. Включает выбор цвета задачи (7 пастельных оттенков).

## Зависимости

- [[store]] — `type Task`
- [[DateRangePicker]] — выбор дат начала/конца задачи
- [[Autocomplete]] — выбор ресурсов из списка
- [[validateUrl]] — валидация URL ссылки
- `@dnd-kit/*` — сортировка кастомных полей внутри модала

## Используется в

- [[TimelinePage]] — открывается при создании/редактировании задачи в Gantt
- [[TasksPage]] — открывается при создании/редактировании задачи в таблице
