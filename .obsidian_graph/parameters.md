# parameters.ts

Утилиты для работы с деревом параметров Timeline. Функции: фильтрация видимых параметров, обработка закреплённых (frozen) строк, рекурсивный поиск параметра по ID, обход дерева.

## Зависимости

Нет внешних зависимостей — чистые утилитарные функции.

## Используется в

- [[TimelinePage]] — вычисления видимых строк и поиск параметров
