# Autocomplete.tsx

Поле ввода с выпадающим списком подсказок, отфильтрованных по введённому тексту. Управляет синхронизацией внешнего значения и обрабатывает фокус/blur.

## Зависимости

Нет внешних зависимостей (только React).

## Используется в

- [[TaskModal]] — выбор ресурсов
- [[ParameterModal]] — выбор родительского параметра
