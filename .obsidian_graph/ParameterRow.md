# ParameterRow.tsx

Строка параметра в боковой панели Timeline. Отображает иконку разворачивания/сворачивания, название параметра и кнопку заморозки/закрепления строки. Управляет hover-состоянием.

## Зависимости

Нет внешних зависимостей (только React + Lucide иконки).

## Используется в

- [[TimelinePage]] — рендер каждого параметра в левой колонке Gantt
